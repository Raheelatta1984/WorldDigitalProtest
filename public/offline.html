Works with no internet

Join from anywhere, on any connection

Internet access is not evenly distributed, so the protest cannot depend on it. There are four ways to join without a data plan or a working network. All four accept the same protocol and land on the same worldwide count.

1 Bluetooth beacon

A phone, laptop or small beacon near you broadcasts a protest packet. Your device picks it up and you join from the app or page it opens.

  • No internet needed to receive the beacon.
  • The packet carries the protest id, protocol hash and a 15-minute pairing code.
  • Absorbed joins are accepted at the moment they reach a network.
A beacon never contains anyone's personal data — only the protest reference and a rotating code.

2 Nearby Wi-Fi hotspot

One person with connectivity shares a hotspot. Anyone in range joins, and no mobile data is used by participants.

  1. Open the protest page on the device with a connection.
  2. Show the pairing code or QR from the protest dashboard.
  3. Others join through the hotspot and land on the same count.

3 Scanned or printed code

Any poster, sticker, wall or screen can carry a protest code. Scan it and join — no account, no app install.

4 Fully offline, synced later

No network at all? Your join is signed on the device, stored, and submitted the next time it reaches any connection — powered by you, an internet café, a hotspot, or a relayed device.

  1. Your device stores a signed join envelope.
  2. It can be relayed by anyone who later gets a connection.
  3. The server verifies the signature before counting it.

Become a relay point

If you have a connection and people around you do not, you can carry their joins. Each envelope is signed with the pairing code it was created under, so a relay cannot forge or inflate a join — it can only deliver it.

What a relay can do
Deliver a genuine offline join created under a valid pairing code.
What a relay cannot do
Create joins, reuse an expired code, change the protocol, or add a country that was not in the envelope.
Technical detail: envelope format 
wdp1.<base64url(beacon json)>                 beacon carried by BLE / QR / print
body.sig                                        signed join envelope
body = { t: "wdp-join", v: "1.0", h: <protocol hash>,
         p: <protest id>, c: <pairing code>,
         iat, exp, nonce }
sig  = HMAC-SHA256(body, sha256("wdp:" + pairingCode + ":" + protocolHash))
