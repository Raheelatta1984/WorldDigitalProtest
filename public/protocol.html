Protocol 1.0

The World Digital Protest Protocol

One protocol for every protest on this platform, for every participant, in every country.

Why one protocol, not many. A protest of millions that never gathers in one place has no crowd to police, no stewards, no local rules. The only thing holding the standard together is that every participant, everywhere, accepts exactly the same rules. There is noorganiser override, no country-specific version, and no way to join partially.

How the protocol is enforced

Before publishing
Calls to violence are blocked when a protest or update is created. The screen returns the exact phrases that failed, so they can be reworded.
At the point of joining
All four agreements are required. A join without them is rejected and not counted.
While running
Anyone can report a breach from any protest page. Reports are queued for review against these articles.
Offline joins
Offline envelopes carry the protocol version and hash they accepted. An envelope made under a different protocol is rejected on sync.

Wire contract

The protocol is also a technical contract, so queued offline data cannot be replayed under different rules.
