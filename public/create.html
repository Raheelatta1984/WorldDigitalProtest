Start a protest

Three things are required: a headline, a reason, and one shared time window. Anything that calls for violence is blocked before it can be published, on every protest, without exception.

What publishing does

Visible immediately
The protest appears on the homepage and the live list for everyone, in every country, at the same moment.
Live KPIs from the first join
Country, city, area, gender, age and channel counts start updating in real time.
A pairing code for offline joining
The code rotates so people can join from posters, beacons and hotspots.
An overlay for the stream
A transparent KPI page your broadcast software can capture for the whole protest.
